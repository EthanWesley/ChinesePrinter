# 长文本点击开始后卡顿

原路径在浏览器主线程同步编码和构造 JSON。设备以 `dd bs=1` 逐字节
读取请求；单行 JSON 使 awk 重复复制长后缀。后台 HID 任务还继承了
HTTP 响应的输出管道，导致命令替换等待任务结束才返回响应。

编码和请求体构造移入 Blob Worker，仍使用同一个转换函数，支持全部
既有编码。请求体保留 JSON 协议，但每个 item 单独一行。准备阶段可
取消且保留输入；发送和打字阶段显示明确状态，阻止重复点击。健康
查询不能用准备/发送期间的旧状态重新启用按钮。

设备改用 `head -c` 按块读取指定字节数；启动前写入 busy 状态，后台
任务重定向 stdin/stdout/stderr，启动后立即返回 HTTP 响应。

验证包括独立线程处理 120000 个输入项时主线程仍可运行、全部编码
转换一致、长 JSON 解析顺序、准备取消/失败，以及真实 Shell HTTP
处理器在模拟慢 HID 任务结束前返回成功。检查产物保留在 Git 忽略的
`.deleted/2026-10-07/` 中。实际设备性能和 USB 输入仍需实机确认。

检查命令：`node tests/encoding.test.cjs`。
